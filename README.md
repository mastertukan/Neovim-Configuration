## Using package managers install the follwing

# Nodejs
```
choco install nodejs nodejs.install -y
```

# Python
```
choco install python311 ripgrep -y
```

# Powershell
```
choco install pwsh -y
```

# Git
```
winget install --id Git.Git -e --source winget
```

# Lua
Probably using winget, but not sure
```
winget install -e --id DEVCOM.Lua
```

# Treesitter
To ensure Treesitter working properly install MSVC (Microsoft Visual C++).

The easiest way is to install it with Microsoft Visual Studio (2022).
